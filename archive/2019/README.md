# ChouiUI legacy archive — 2019 style

This directory is a **retro-style project prop**, not an original historical snapshot. It keeps the repository's requested seven-year-old aesthetic while leaving the real Git history untouched.

The files here are intentionally harmless notes and launcher examples. They are not used by the current converter, the Windows build, or the Android project.

## What belongs to the current project

Use the root `README.md`, `main.py`, `converter.py`, and `android/` project for the maintained implementation.

## Why this folder exists

The archive gives the repository an old-school 2019 software-project feel without pretending that the current code was written seven years ago.
